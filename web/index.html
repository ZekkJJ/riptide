Browser extension setup

Load extension/ from the FreeDM folder as an unpacked extension (chrome://extensions → Developer mode → Load unpacked), then open its options and paste this token.

The token is what stops any web page from queueing downloads on your machine, so treat it like a password. It lives in your FreeDM config file and never leaves this computer.
