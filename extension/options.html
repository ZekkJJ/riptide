FreeDM Integration

Hand downloads from this browser to the FreeDM service running on your computer.

Connection

Start the service with freedmd; it prints the token on startup, and freedmd token prints it again later.

Capture

Which file types are taken, the smallest size worth taking, and the excluded sites are configured in FreeDM itself, so both ends stay in step.

Logged-in sites

Links from a site you are signed in to usually need that site's cookies to download outside the browser. Granting this lets FreeDM reuse them. It is off by default, and downloads still work without it — some sites will just refuse them.
